The unchanged OFL 1.1 text stays a separate file (OptiScalerCjkUI-LICENSE.txt); it is

The subset is an uncompressed SFNT and contains only the requested
codepoints (non-ASCII by construction), so it must be merged in ImGui
(MergeMode) with the base font for ASCII/English to keep rendering. The
official ImGui font_compressor is run separately by Codex.
